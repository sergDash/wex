# wex-code: подсветка кода

Плагин Wex 3 для подсветки кода в стиле Torchlight. Без зависимостей, без jQuery, CSS встроен.

- Языки: `php`, `js`, `html`, `css`, `json`, `blade`.
- Аннотации в комментариях: `highlight`, `++` / `--` (diff), `focus`, `fold`, `collapse:N`.
- Номера строк, заголовок с именем файла, кнопка Copy.
- Светлая и тёмная тема через CSS-переменные.
- Работает как директива Wex (`w-code`) и без Wex (`highlight()`, `highlightAll()`).

## Подключение

Сборка: исходник `src/plugins/highlighter/wex-code.js`, в `webpack.config.js` (Rolldown) третьим аргументом нужно указать глобал, иначе соберётся ES-модуль и `<script>` его не примет:

```js
const highlighter = createPluginConfigs('highlighter', 'wex-code', 'WexCode');
```

На выходе `dist/plugins/wex-code.js` и `dist/plugins/wex-code.min.js`. Порядок подключения: сначала ядро, потом плагин.

```html
<script src="dist/wex.js"></script>
<script src="dist/plugins/wex-code.js"></script>
<script>
    WexCode.install(Wex);   // до создания view
</script>
```

`install(Wex, settings)` регистрирует директиву-атрибут `w-code`. Директивы Wex копируются во view при создании, поэтому `install` вызывают **до** `Wex.view(...)` / `$('#tpl').state(...)`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `name` | `'w-code'` | Имя атрибута директивы (точное, с префиксом) |
| `css` | `true` | `false`: не вставлять встроенный CSS (см. «Стили») |
| `defaults` | `{}` | Опции по умолчанию для всех блоков, например `{ numbers: true }` |

## Директива `w-code`

Значение атрибута это выражение Wex (ScopeX). Wex значение не интерполирует, поэтому `{{ }}` внутри него не нужны.

Строка означает язык, код берётся из содержимого элемента:

```html
<pre w-code="'php'">echo 'hi';</pre>
```

Объект позволяет передать код и опции:

```html
<pre w-code="{ lang: 'blade', code: snippet, title: 'index.blade.php', numbers: true }"></pre>
```

```js
const app = Wex.$('#app').state(() => ({
    snippet: "@if ($user) {{ $user->name }} @endif",
}));
```

> **Важно: код с `{{ }}` передавайте через `code`.** Если Blade- или Vue-пример лежит текстом внутри `<pre>`, Wex попытается вычислить `{{ ... }}` как собственные выражения. Строка из state для него просто данные.

Блок перерисовывается при изменении `code`, `lang`, `title`, `numbers`, `start` или `copy`. На остальные изменения state директива не реагирует.

`<pre>` не заменяется, плагин пишет внутрь него (`innerHTML`) и добавляет классы `tl`, `tl-nums`, `tl-has-focus`. Это безопасно для Wex.

### Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `lang` | из `data-lang`/`lang`/`class="language-x"` | Язык |
| `code` | текст элемента | Исходный код |
| `title` | `''` | Заголовок (имя файла) в шапке |
| `numbers` | `false` | Номера строк |
| `start` | `1` | Номер первой строки |
| `copy` | `true` | Кнопка Copy |
| `dedent` | `true` | Убрать общий отступ у всех строк |
| `copyLabel` / `copiedLabel` | `Copy` / `Copied` | Подписи кнопки |
| `foldLabel` | `n => n + ' lines'` | Подпись свёрнутой группы, получает число строк |

Те же опции можно задать атрибутами элемента: `data-title`, `data-numbers` (`"false"` выключает), `data-copy="false"`, `data-start`, а язык через `data-lang` или `lang`. Значения из объекта `w-code` приоритетнее атрибутов.

## Языки

| Язык | Алиасы | Что подсвечивается |
|---|---|---|
| `php` | | Классы, функции, переменные, свойства `->`, константы `::`, строки с `$var` и `{$expr}`, heredoc, атрибуты `#[...]` |
| `js` | `javascript`, `mjs`, `cjs`, `jsx`, `ts`, `typescript` | Шаблонные строки с `${}`, регулярки, классы. TypeScript подсвечивается как JS |
| `html` | `htm`, `xml`, `svg`, `vue`, `phtml` | Теги, атрибуты, `<script>` (JS), `<style>` (CSS), `<?php ... ?>`, `{{ expr }}` Wex как JS |
| `css` | | Селекторы, свойства, `var(--x)`, цвета, единицы, `!important`, вложенность |
| `json` | `jsonc` | Ключи и значения, комментарии |
| `blade` | `blade.php` | HTML плюс `{{ }}`, `{!! !!}`, `{{-- --}}`, `@директивы(...)`, `@php ... @endphp`, `<x-...>`, PHP внутри выражений |

Неизвестный язык выводится без цветов, но аннотации, номера строк и Copy работают.

## Аннотации

Аннотация это комментарий вида `[tl! флаги]` в конце строки или отдельной строкой. Подходят любые комментарии: `//`, `#`, `/* */`, `<!-- -->`, `{{-- --}}`. Сам комментарий в вывод не попадает. Если он стоит один на строке, строка удаляется, а номера строк пересчитываются.

```php
$users = User::all();            // [tl! --]
$users = User::latest()->get();  // [tl! ++ focus]
```

```blade
<x-user-card :user="$user" /> {{-- [tl! highlight] --}}
```

| Флаг | Алиасы | Действие |
|---|---|---|
| `highlight` | `hl` | Фон строки и акцентная полоса слева |
| `++` | `add` | Строка добавлена: зелёный фон и `+` |
| `--` | `del`, `remove` | Строка удалена: красный фон и `−` |
| `focus` | | Остальные строки блока тускнеют, при наведении на блок возвращаются |
| `fold` | | Свернуть тело блока `{ ... }`, начатого на этой строке |
| `collapse:N` | | Свернуть N строк, идущих ниже |

Флаги комбинируются через пробел: `[tl! ++ focus]`.

### Диапазоны

К флагу добавляется `:N`:

- Аннотация в конце строки с кодом: флаг действует на эту строку и на N−1 следующих (`highlight:3` это три строки, считая текущую).
- Аннотация на отдельной строке: флаг действует на N строк ниже неё.

```js
// [tl! ++:2]
const a = 1;
const b = 2;
```

### Свёртывание

Свёрнутые строки заменяются кнопкой «N lines». Клик раскрывает и сворачивает группу.

- `fold` ищет парную `}` для первой `{`, открывшейся с этой строки (подходит и `{` на следующей строке, как в Allman-стиле). Скрывается всё между строкой с `{` и строкой с `}`, закрывающая строка остаётся видимой. Работает для языков со скобками (php, js, css). Для HTML-тегов и директив Blade не работает, там используйте `collapse:N`.
- `collapse:N` скрывает N строк подряд ниже, независимо от скобок.
- Если `fold` стоит на отдельной строке, он применяется к следующей строке.

```php
public function export() // [tl! fold]
{
    // эти строки будут свёрнуты
}
```

### Copy

Кнопка копирует чистый код: без аннотаций, со свёрнутыми строками, без строк `--`.

## API без Wex

```js
// строка с готовым <pre class="tl">
el.innerHTML = WexCode.highlight(code, 'php', { numbers: true, title: 'a.php' });

// на месте, без замены элемента
WexCode.highlightElement(document.querySelector('pre'), { lang: 'js' });

// все pre[data-lang], pre[lang] и pre > code.language-x на странице
WexCode.highlightAll();
```

| Функция | Возвращает | Описание |
|---|---|---|
| `install(Wex, settings)` | | Регистрирует директиву `w-code` |
| `highlight(code, lang, opts)` | `string` | Готовый `<pre>` |
| `highlightElement(el, opts)` | элемент | Подсвечивает `<pre>` (или `<pre><code>`) на месте |
| `highlightAll(root?)` | | Подсвечивает всё найденное в `root` (по умолчанию `document`) |
| `tokenize(code, lang)` | `[[тип, текст], ...]` | Токены без потерь: склейка текстов равна исходнику |
| `css` | `string` | Встроенные стили |
| `defaults` | `object` | Опции по умолчанию (можно менять) |

Кнопки fold и Copy работают через один делегированный обработчик `click` на `document`. Он ставится при первом вызове подсветки.

## Стили

CSS встроен в JS и вставляется один раз в начало `<head>` как `<style id="wex-code-css">`. Он стоит первым, поэтому стили проекта (Quas) могут переопределять переменные и правила.

Отключить вставку (например, при строгой CSP без `unsafe-inline` для стилей) и подключить стили самому:

```js
WexCode.install(Wex, { css: false });
// WexCode.css содержит строку со стилями
```

### Тёмная тема

Переменные переключаются классом `.dark` (на `html`, `body` или любом предке) или атрибутом `data-theme="dark"`. Без явного выбора тема следует `prefers-color-scheme`. Чтобы принудительно включить светлую, поставьте `.light` или `data-theme="light"` на `html`.

### Переменные

```css
:root {
    --tl-bg: #f6f8fa;       /* фон блока */
    --tl-fg: #24292f;       /* основной текст */
    --tl-border: #d0d7de;
    --tl-muted: #6e7781;    /* шапка, кнопка fold */
    --tl-gutter: #8c959f;   /* номера строк */
    --tl-hl: rgba(175, 184, 193, .26);   /* highlight, hover fold */
    --tl-accent: #8250df;                /* полоса highlight, outline фокуса */
    --tl-add: rgba(46, 164, 79, .16);  --tl-add-fg: #1a7f37;
    --tl-del: rgba(255, 129, 130, .2); --tl-del-fg: #cf222e;
}
```

Цвета токенов: `--tl-k`, `--tl-c`, `--tl-s`, `--tl-n`, `--tl-cm`, `--tl-f`, `--tl-cl`, `--tl-v`, `--tl-o`, `--tl-p`, `--tl-tag`, `--tl-at`, `--tl-pr`, `--tl-d`, `--tl-e`, `--tl-sel`.

### Классы токенов

| Класс | Что это |
|---|---|
| `tl-k` | Ключевое слово |
| `tl-c` | Константа (`true`, `null`, `Foo::BAR`, `$this`) |
| `tl-s` | Строка, регулярка |
| `tl-n` | Число, цвет, единицы CSS |
| `tl-cm` | Комментарий |
| `tl-f` | Вызов функции |
| `tl-cl` | Класс, тип |
| `tl-v` | Переменная (`$var`, `--custom-prop`) |
| `tl-o` | Оператор |
| `tl-p` | Пунктуация, скобки |
| `tl-tag` | HTML-тег |
| `tl-at` | HTML-атрибут |
| `tl-pr` | Свойство (ключ объекта, JSON, CSS, `->prop`) |
| `tl-d` | Директива Blade |
| `tl-e` | Escape, границы интерполяции (`{{`, `${`) |
| `tl-sel` | CSS-селектор |

Разметка блока:

```html
<pre class="tl tl-nums tl-has-focus" data-lang="php">
    <span class="tl-head">… заголовок и кнопка Copy …</span>
    <code class="tl-code">
        <span class="tl-line tl-add" data-n="1">…токены…</span>
        <span class="tl-fold">
            <button class="tl-fold-btn">…</button>
            <span class="tl-fold-body">…строки…</span>
        </span>
    </code>
</pre>
```

## Ограничения

- Токенайзер основан на регулярках, это не полноценный парсер. На необычных конструкциях (вложенные heredoc, регулярки после `}`) возможны неточности.
- Значения атрибутов Wex (`w-if="..."`, `w-on="..."`) подсвечиваются как строки, без разбора выражений.
- `fold` по скобкам не работает для HTML и директив Blade.
- Подсветка `{{ }}` в `html`: содержимое всегда как JS, в `blade` как PHP.
- Целевые браузеры: iOS 15+ и последние Chrome/Firefox (без lookbehind и `:has`).
