# Wex DatePicker: справочник

Плагин и два компонента для Wex: `DatePicker` (дата) и `DateTimePicker` (дата и время). Инпут с маской, календарь, выбор месяца и года, стили на Quas, тёмная тема через `dark:`.

Пометка `(не проверено)` стоит у того, что написано по коду, но ещё не прогонялось в браузере. Логика маски, кликов по сегментам, выбора месяца, года и времени проверена тестами на заглушках Wex.

<a id="quickstart"></a>

## Быстрый старт

```html
<script>window.Quas = { AutoDarkMode: false };</script>
<script src="https://cdn.jsdelivr.net/gh/wemmbley/quas@master/Source/Quas.js"></script> <!-- jQuery раньше Wex -->
<script src="https://cdn.jsdelivr.net/gh/wemmbley/wex@3.x/dist/wex.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/wemmbley/wex@3.x/dist/plugins/wex-datepicker.min.js"></script>                                  <!-- после Wex -->

<template id="app">
  <DatePicker :value="date" @change="onDate"></DatePicker>
  <DateTimePicker :clickableMonth="true" :clickableYear="true" :value="dt" @change="onDt"></DateTimePicker>
</template>

<script>
const dp = createDatePicker()

$('#app')
  .state({ date: '2026-11-12', dt: '2026-11-12 23:32' })
  .method('onDate', state => function (v) { state.date = v })
  .method('onDt', state => function (v) { state.dt = v })
  .plugin(dp)
  .mount()
</script>
```

| Принцип | Что значит |
|---|---|
| Плагин и компоненты | `createDatePicker(options)` регистрирует глобально `DatePicker` и `DateTimePicker` и возвращает функцию для `.plugin()` |
| Значение у родителя | Компонент не хранит «свою» дату насовсем: он показывает prop `value` и сообщает о выборе событием `@change` |
| Теги | Закрываются явно: `<DatePicker></DatePicker>`, не `<DatePicker/>` |

<a id="props"></a>

## Props и события

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `value` | строка | `''` | Текущее значение ([формат](#value)). Родитель может менять его в любой момент |
| `clickableMonth` | булево | опция (`false`) | Клик по месяцу **в инпуте** открывает выбор месяца |
| `clickableYear` | булево | опция (`false`) | Клик по году **в инпуте** открывает выбор года |
| `placeholder` | строка | из формата | Например `дд/мм/гггг` |
| `format` | строка | из опций | Формат отображения для этого экземпляра |
| `@change` | событие | нет | Получает новое значение (`''` при очистке) |

```html
<DatePicker :clickableMonth="true" :clickableYear="true"></DatePicker>
<DatePicker clickableMonth="true" value="2000-12-22"></DatePicker>
```

Флаги принимают `true` или `'true'`. Wex отдаёт компоненту только props, которые есть в его state, поэтому опечатка в имени тихо игнорируется.
Начальное значение задаётся prop'ом `value`, а не содержимым тега: так компонент не теряет state.

<a id="value"></a>

## Значение и формат

| Компонент | Формат `value` | Пример |
|---|---|---|
| `DatePicker` | `YYYY-MM-DD` | `2026-11-12` |
| `DateTimePicker` | `YYYY-MM-DD HH:mm` | `2026-11-12 23:32` |

Разделитель между датой и временем может быть пробелом или `T`. Пустое значение это `''`. Некорректная строка читается как пустая.
Значение приходит и уходит в ISO-виде, а в инпуте показывается по формату отображения:

| Токен | Что значит |
|---|---|
| `dd` | День, 2 цифры |
| `MM` | Месяц, 2 цифры (заглавные, чтобы не путать с минутами) |
| `yyyy` | Год, 4 цифры |
| `HH` | Часы |
| `mm` | Минуты |

По умолчанию `dd/MM/yyyy` и `dd/MM/yyyy HH:mm`. Меняется в опциях (`formats`) или на экземпляре (`format="dd.MM.yyyy"`). Разделители любые.

Внешнее изменение `value` (родитель присвоил новое значение, например сбросил форму) подхватывается: инпут, календарь и выбранный день обновляются. (не проверено)

<a id="input"></a>

## Ввод в инпут

Инпут с цифровой клавиатурой и маской формата: вводятся только цифры, разделители подставляются сами.

| Ситуация | Что происходит |
|---|---|
| Ввод цифр | `12` показывается как `12`, `123` как `12/3`, `12122000` как `12/12/2000` |
| Лишние символы | Буквы отбрасываются, лишние цифры тоже |
| Дата введена полностью и корректна | Значение сразу меняется, вызывается `@change`, календарь перелистывается на эту дату |
| Дата введена полностью, но невалидна (`31/02/2026`) | Значение не меняется |
| Потеря фокуса | Неполная или невалидная строка откатывается к последнему валидному значению |
| Поле очищено целиком | Значение сбрасывается в `''` |
| Каретка | При правке в середине остаётся на месте (`setSelectionRange`) |

Допустимый год 1000–9999. Вставка из буфера отдельно не обрабатывается.

<a id="clicks"></a>

## Клики: что открывается

Что открывается, зависит от того, **по какой части текста** в инпуте кликнули (определяется по положению каретки).

| Клик | Флаг выключен (по умолчанию) | Флаг включён |
|---|---|---|
| По дню | Весь календарь | Весь календарь |
| По месяцу | Весь календарь | Панель выбора месяца (`clickableMonth`) |
| По году | Весь календарь | Панель выбора года (`clickableYear`) |
| По часам и минутам, по разделителям | Весь календарь | Весь календарь |
| Иконка-стрелка справа | Открывает и закрывает календарь | Так же |

Месяц и год в панели берутся **из текста в инпуте**, даже если дата ещё не введена целиком: `31/03/` покажет выбранным март.
Клики по месяцу и году **в шапке календаря** работают всегда, независимо от флагов.

<a id="panels"></a>

## Календарь и панели

Попап показывает одну панель за раз: календарь, список месяцев или список годов. После выбора пункта списка возвращается календарь.

| Действие | Результат |
|---|---|
| Клик по дню | Значение меняется. `DatePicker` закрывается, `DateTimePicker` остаётся открытым (нужно выбрать время) |
| Стрелки `‹` `›` | Листают отображаемый месяц, значение не меняют |
| Клик по месяцу или году в шапке | Заменяет календарь списком. Выбранный пункт по центру списка |
| Выбор месяца или года в списке | **Значение меняется сразу**: день сохраняется, при необходимости уменьшается (`31` января в феврале станет `28`/`29`). Время сохраняется |
| Выбор месяца или года, значения ещё нет | Меняется только отображаемый месяц, значение не появляется |
| Список годов | Текущий год ±60 по умолчанию. Если значение вне диапазона, диапазон расширяется |
| Escape, клик вне компонента | Закрывает попап |

Календарь всегда показывает 6 недель (42 дня), дни соседних месяцев приглушены.

<a id="datetime"></a>

## DateTimePicker

Рядом с календарём две колонки: часы (0–23) и минуты (0–59). Прокручиваются колесом или свайпом, выбранное значение по центру колонки.

| Нюанс | Пояснение |
|---|---|
| Выбор времени | Меняет значение сразу, если дата уже выбрана |
| Дата ещё не выбрана | Выбор часа и минуты запоминается и применяется вместе с днём. Значение не появляется |
| Колонки при панели месяца или года | Остаются на месте |
| Формат | По умолчанию `dd/MM/yyyy HH:mm`. Ввод вручную требует и дату, и время |

<a id="options"></a>

## Опции createDatePicker

```js
const dp = createDatePicker({
  clickableMonth: true,
  formats: { date: 'dd.MM.yyyy', datetime: 'dd.MM.yyyy HH:mm' },
  weekStart: 0
})
```

| Опция | По умолчанию | Описание |
|---|---|---|
| `clickableMonth` | `false` | Значение по умолчанию для всех компонентов. Prop в теге переопределяет |
| `clickableYear` | `false` | То же для года |
| `formats` | `dd/MM/yyyy`, `dd/MM/yyyy HH:mm` | Форматы отображения (`date`, `datetime`) |
| `tokenLabels` | `дд`, `мм`, `гггг`, `чч`, `мм` | Подписи токенов для placeholder |
| `months` | русские | 12 названий, с января |
| `weekdays` | `Вс … Сб` | 7 подписей **с воскресенья** (порядок `Date.getDay()`) |
| `weekStart` | `1` | Первый день недели: `1` понедельник, `0` воскресенье |
| `locale` | `'ru-RU'` | Только для `aria-label` дней |
| `yearsBefore`, `yearsAfter` | `60` | Диапазон списка годов вокруг текущего года |
| `labels` | русские | Подписи кнопок и панелей: `prevMonth`, `nextMonth`, `toggle`, `pickDate`, `pickDateTime`, `hour`, `minute`, `months`, `years` |

Объекты `formats`, `tokenLabels`, `labels` сливаются с умолчаниями на один уровень, а `months` и `weekdays` заменяются целиком.

<a id="locale"></a>

## Локализация

По умолчанию всё русское. Свой язык задаётся при инициализации:

```js
createDatePicker({
  locale: 'en-US',
  months: ['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'],
  weekdays: ['Su', 'Mo', 'Tu', 'We', 'Th', 'Fr', 'Sa'],
  weekStart: 0,
  tokenLabels: { dd: 'dd', MM: 'mm', yyyy: 'yyyy', HH: 'hh', mm: 'mm' },
  labels: { prevMonth: 'Previous month', nextMonth: 'Next month', toggle: 'Open calendar' }
})
```

<a id="position"></a>

## Позиция попапа

| Что | Как |
|---|---|
| По умолчанию | Под инпутом, левый край по левому краю инпута, поверх контента (`absolute`) |
| Нет места снизу | Если снизу меньше места, чем сверху, и попап не помещается, он открывается над инпутом |
| Узкий экран | Максимальная ширина `100vw − 2rem`: колонки времени переносятся под календарь |

Положение считается после рендера (примерно через 50 мс), поэтому при открытии возможно короткое мерцание. (не проверено)
Горизонтальный разворот (если инпут у правого края) не делается.

<a id="theme"></a>

## Quas и тема

Тёмная тема работает через `dark:` (класс `dark` на `<html>`). Если тема переключается вручную, в Quas нужен `window.Quas = { AutoDarkMode: false }` до подключения `Quas.js` (см. справочник Quas, раздел «Тёмная тема»).

| Что | Как |
|---|---|
| Классы | Только Quas: сетка, flex, `snap-*`, `overscroll-contain`, `touch-pan-y`, `w-max`, `max-w-[calc(100vw-2rem)]`, `shadow-[…]` |
| Скрытый скроллбар колонок времени | Quas не умеет `scrollbar-width`, поэтому плагин один раз вставляет `<style id="wex-datepicker-css">` с классом `dp-hide-sb` |
| Динамические классы | Подсветка выбранного дня и пунктов списка собирается в JS и вставляется интерполяцией `class="… {{ cls }}"`, не `w-class` |
| Список для `traceby` | Дни, пункты списков, часы и минуты идут массивами из состояния (по одному циклу, без вложенности) |

<a id="pitfalls"></a>

## Частые ошибки и ограничения

| Симптом | Причина и решение |
|---|---|
| Флаг в теге не действует | Prop не из state: проверьте имя (`clickableMonth`, `clickableYear`). Значение должно быть `true` или `'true'` |
| Клик по месяцу открывает календарь | Флаг выключен (по умолчанию). Включите `:clickableMonth="true"` или опцию при инициализации |
| `@change` не вызывается | Handler не зарегистрирован через `.method('onX', state => function (v) {...})` или значение не изменилось |
| После выбора день в инпуте «поехал» | Выбор месяца или года меняет значение, день зажимается до длины месяца |
| Значение не меняется после ввода | Дата неполная или невалидна (`31/02`): при потере фокуса откатится |
| Не работает `value` в Date-формате с точками | Значение всегда ISO (`2000-12-22`); формат с точками задаётся через `formats` |
| Колонки времени без прокрутки колесом | Нужны `overscroll-contain` и `touch-pan-y` (есть в шаблоне); проверьте, что Quas подключён |
| Пустой `<DatePicker/>` | Теги компонентов закрываются явно |
| Ошибка валидации формы не видна | В v1 компонент не выводит ошибки и не создаёт скрытое поле для отправки формы: решается в Blade отдельно |

## Чего нет в v1

| Возможность | Статус |
|---|---|
| `min`, `max`, отключённые дни | Не делали |
