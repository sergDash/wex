## 1. Подключение

Порядок свят: jQuery, Wex, плагин, `mount()`.

```html
<script src="https://cdn.jsdelivr.net/gh/wemmbley/wex@3.x/dist/wex.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/wemmbley/wex@3.x/dist/plugins/wex-gallery.js"></script>                                              <!-- после Wex -->

<script>
    $('#app').state({ ... }).mount()
</script>
```

Плагин регистрирует компоненты через `window.jqvm`. Нет `jqvm` — нет компонентов, но директивы `w-zoom-*` и разметка `wg-*` продолжат жить.

Стили инжектируются сами, один раз, первым тегом в `<head>`. Любой ваш класс их перебьёт — это сделано намеренно.

## 2. Одна картинка

```html
<w-image :url="photo.thumb" :full="photo.big"></w-image>
```

Клик — лайтбокс. `alt` — из имени файла (`forest-lake.jpg` → `forest lake`). Ленивая загрузка включена.

Тег `<Image>` не работает, и это не обсуждается: HTML-парсер превращает `<image>` в `<img>` до того, как Wex что-либо увидит. Префикс `w-` — единственный способ. Закрывающий тег обязателен: `<w-image></w-image>`.

| Проп | Что делает |
|---|---|
| `url` (алиас `src`) | Картинка на странице |
| `full` | Большая версия для лайтбокса. По умолчанию равна `url` |
| `thumb` | Миниатюра для `thumbs-of`. По умолчанию равна `url` |
| `alt` | Описание. Нет — берётся из имени файла. `alt=""` — декоративная |
| `lightbox` | `false` отключает клик. По умолчанию `true` |
| `lazy` | `false` отключает `loading="lazy"`. По умолчанию `true` |

Всё остальное (`class`, `style`, `id`, `w-zoom-lense`, `w-caption`) копируется на обёртку `.wg-image`. Размеры — ваши, классами.

```html
<w-image :url="p.img" class="w-64 h-48 rounded" :alt="p.title"></w-image>
```

## 3. Лайтбокс

Один на страницу. Рендерится в `<body>`, поэтому `overflow:hidden`, `transform` и `z-index` родителей ему не страшны.

Для компонента он включён сам. Для обычного `<img>` — директива:

```html
<img src="thumb.jpg" alt="" w-zoom-lightbox>
```

Откуда берётся большая картинка, по приоритету:

1. `w-full="..."` на элементе
2. `data-wg-full="..."`
3. `href` родительского `<a>`, если ссылка ведёт на картинку
4. сам `src`

Классика деградирует без JS:

```html
<a href="big.jpg"><img src="thumb.jpg" alt="" w-zoom-lightbox></a>
```

Подпись: `w-caption="Лес в тумане"`.

Управление: клик по фону, `Esc`, стрелки, `Home`/`End`, свайп влево-вправо. Скролл страницы блокируется, фокус возвращается на кликнутый элемент.

## 4. Лупа

Квадрат, который увеличивает область под курсором. Только там, где есть hover: на тачах её нет и не будет.

```html
<w-image :url="a" :full="b" w-zoom-lense></w-image>
<img src="a.jpg" w-zoom-lense w-full="b.jpg">
```

Увеличивается `full`, а не превью. Нет `full` — увеличивается `src`.

Тонкая настройка на самом элементе:

| Атрибут | Что делает |
|---|---|
| `w-zoom-lense="3"` | Кратность. Число в значении — это зум |
| `w-lens-zoom="3"` | То же, явнее |
| `w-lens-size="200"` | Размер в пикселях |
| `w-lens-shape="circle"` | `square` (по умолчанию) или `circle` |

Внутри лайтбокса лупы по умолчанию нет. Включается отдельным тегом:

```html
<w-image :url="a" :full="b" w-zoom-lense w-lightbox-lense></w-image>
```

`w-zoom-lense` — лупа на странице. `w-lightbox-lense` — лупа в оверлее. Они независимы.

Орфография `lense` выбрана осознанно, так в шаблонах и пишем. В CSS и JS-API везде `lens`.

## 5. Группы

Картинки, открытые одним лайтбоксом, листаются стрелками.

**Внутри карусели** — группа образуется сама. Все картинки с `w-zoom-lightbox` внутри одной `<Carousel>` — одна галерея.

**Вне карусели** — явно:

```html
<img w-for="p in photos traceby p.id" w-src="p.thumb" alt="{{ p.title }}"
     w-zoom-lightbox w-gallery="trip" data-wg-full="{{ p.full }}">
```

Одинаковое значение `w-gallery` по всей странице — одна группа. Без `w-gallery` и вне карусели картинка открывается одна.

## 6. Карусель

```html
<Carousel :autoslide="true" :interval="3000" :loop="true"
          :navigate-arrows="true" :navigate-dots="true">
    <w-image :url="a"></w-image>
    <w-image :url="b"></w-image>
    <w-image :url="c"></w-image>
</Carousel>
```

Слайд — это прямой ребёнок. Не обязательно картинка: карточка товара, блок текста, видео. Пустая строка и комментарии Wex отбрасываются, остальное оборачивается в слайд.

`w-for` работает на ребёнке:

```html
<Carousel>
    <div class="card" w-for="p in products traceby p.id">{{ p.title }}</div>
</Carousel>
```

### Пропсы

| Проп | По умолч. | Что делает |
|---|---|---|
| `autoslide` | `false` | Автопрокрутка |
| `interval` | `4000` | Пауза между слайдами: `3000`, `"3s"`, `"3000ms"`. Минимум 500 |
| `loop` | `false` | Переход с последнего на первый, и наоборот |
| `hover-pause` | `true` | Стоп при наведении, касании, фокусе клавиатуры, скрытой вкладке |
| `navigate-arrows` | `false` | Стрелки (алиас `navigation`) |
| `navigate-dots` | `false` | Точки |
| `direction` | `horizontal` | `horizontal` или `vertical` |
| `per-view` | `1` | Сколько слайдов видно. Число или объект, см. [адаптив](#8-адаптив) |
| `gap` | `0` | Зазор в пикселях. Число или объект |
| `breakpoints` | | Свои именованные пороги |
| `step` | `1` | На сколько слайдов шаг стрелки |
| `start` | `0` | Стартовый слайд |
| `mouse-drag` | `true` | Перетаскивание мышью. Касанием листается нативно |
| `name` | | Имя для связки с превью. Строка |
| `thumbs-of` | | Превращает карусель в ленту превью другой. Строка |
| `label` | `Carousel` | `aria-label` |
| `slide-class` | | Классы на каждый слайд |

Три нюанса.

**Без `loop` автослайд останавливается на последнем слайде.** Он не мотается назад сам. Нужен цикл — включайте `loop`.

**`loop` — это wrap-around, не бесконечность.** С последнего на первый проезжаем плавно, обратно. Клонов слайдов нет, и это плюс: инпуты, события и группы лайтбокса в слайдах не дублируются.

**Точек столько, сколько достижимых позиций, а не слайдов.** Шесть слайдов по три в ряд — четыре точки. Это честно: четыре положения.

Движок — нативный `overflow` с `scroll-snap`. Свайп, инерция, вертикаль приходят бесплатно. Мышь допилена Pointer Events. Если палец или мышь сдвинулись больше чем на 6px, клик подавляется: свайп не открывает лайтбокс.

## 7. Своя навигация

Служебные дети вырезаются из потока слайдов и остаются на своих местах. Встроенная навигация при этом выключается сама.

```html
<Carousel :loop="true">
    <div w-navigate-left>&lsaquo;</div>

    <w-image :url="a"></w-image>
    <w-image :url="b"></w-image>

    <div w-navigate-right>&rsaquo;</div>
    <div w-navigate-dots class="flex gap-2"></div>
    <button w-goto="2">К третьему</button>
</Carousel>
```

| Атрибут | Что делает |
|---|---|
| `w-navigate-left` / `w-navigate-right` | Ваш элемент становится стрелкой. Прямой ребёнок карусели |
| `w-navigate-dots` | Контейнер для точек. Точки внутрь добавит плагин |
| `w-goto="N"` | Клик переходит к слайду N (с нуля) |
| `w-goto-of="name"` | Тот же `w-goto`, но для карусели с именем `name`. Работает откуда угодно |

Недоступное действие (в начале без `loop`) получает `data-wg-disabled` и `aria-disabled`. Стилизуйте: `[data-wg-disabled] { opacity: .3 }`. Встроенный стиль уже есть.

Вместо `<` пишите `&lsaquo;` или `&lt;`. Голый `<` в тексте парсер может принять за начало тега.

Нужна кнопка вне карусели:

```html
<button w-goto="0" w-goto-of="product">К первому фото</button>
```

## 8. Адаптив

Ширина слайда в карусели — это CSS. Плагин не меряет пиксели, он читает то, что нарисовал браузер. Отсюда два способа, оба рабочие.

### Способ первый: классы Quas

Призрачный `div` с `w-carousel-adaptive`: его классы копируются на каждый слайд. Сам он в DOM не попадает.

```html
<Carousel :gap="16" :navigate-arrows="true">
    <div w-carousel-adaptive class="w-full sm:w-1/2 md:w-1/4"></div>
    <div class="card" w-for="p in products traceby p.id">{{ p.title }}</div>
</Carousel>
```

То же без призрака:

```html
<Carousel slide-class="w-full md:w-1/4" :gap="16"> ... </Carousel>
```

Ширина по умолчанию задана через `:where()`, то есть с нулевой специфичностью. Любой ваш класс побеждает.

### Способ второй: без Tailwind и Quas

Именованные пороги, mobile-first (`min-width`):

```html
<Carousel :breakpoints="{ sm: 600, md: 900 }"
          :per-view="{ base: 1, sm: 2, md: 4 }"
          :gap="{ base: 8, md: 16 }">
```

`base` — всё, что меньше первого порога. Порог можно писать числом: `{ 0: 1, 768: 2 }`.

Встроенные имена, если `breakpoints` не заданы: `sm 640`, `md 768`, `lg 1024`, `xl 1280`, `2xl 1536`. Менять глобально — в [настройках](#14-настройки).

Размер карусели в скрытом табе или аккордеоне считается заново, когда она становится видимой: `ResizeObserver`.

## 9. События

Два способа слушать.

**Методом Wex:**

```html
<Carousel @slide="onSlide" @ready="onReady"> ... </Carousel>
```

```js
$('#app')
    .state({ current: 1 })
    .method('onSlide', function (state) {
        return function (e) { state.current = e.detail.index + 1 }
    })
    .mount()
```

**Нативным событием DOM:**

```js
document.querySelector('.wg-carousel').addEventListener('wslide', (e) => {
    console.log(e.detail.index, e.detail.count)
})
```

События: `wready` (первый расчёт готов), `wslide` (активный слайд изменился). Всплывают.

`e.detail`: `{ index, count, name, carousel }`.

Параметры в вызове работают: `@slide="onSlide(5)"`.

## 10. Превью (thumbs)

Превью — это тоже `<Carousel>`, только без детей и с ссылкой на главную. Один движок, ноль нового API.

```html
<Carousel name="product" :navigate-arrows="true">
    <w-image w-for="p in photos traceby p.id" :url="p.full" :thumb="p.thumb"></w-image>
</Carousel>

<Carousel :thumbs-of="product" :per-view="5" :gap="8"></Carousel>
```

Связь по имени. `name="product"` и `:thumbs-of="product"` — это одна строка `product`. Если переменной `product` в состоянии нет, имя берётся как есть. Есть — берётся её значение. Строка ссылается на строку, не на переменную.

Что происходит:
- плагин строит миниатюры из слайдов главной карусели;
- источник миниатюры: `:thumb` у `<w-image>`, затем `data-thumb`, затем первый `src` внутри слайда;
- клик по миниатюре переключает главную;
- активная миниатюра получает `wg-active` и `aria-current`;
- лента сама подкручивается, чтобы активная была видна;
- слайды главной изменились (пришли данные, `w-for` перерисовался) — превью пересобираются.

Превью можно размещать где угодно: снизу, сбоку, в другом месте страницы. Порядок в разметке не важен.

Автослайд на ленте превью не работает: им управляет главная.

## 11. Вертикаль

```html
<Carousel direction="vertical" :per-view="4" :gap="8" ...></Carousel>
```

Вертикальная карусель берёт высоту у родителя и сама её не придумывает. Нет высоты — будет `min-height: 12rem`. Дайте контейнеру высоту (`h-[420px]`) или растяните flex-ом.

Всё остальное то же: свайп, колесо, стрелки (повёрнуты), точки (справа), клавиши `↑` и `↓`.

## 12. Галерея товара целиком

Вертикальные превью слева, большая картинка справа. Лупа на странице, лайтбокс по клику.

```html
<div class="flex gap-4" style="height: 420px">
    <div style="width: 96px">
        <Carousel :thumbs-of="product" direction="vertical" :per-view="4" :gap="8"></Carousel>
    </div>

    <div style="flex: 1; min-width: 0; height: 100%">
        <Carousel name="product" :navigate-arrows="true" style="height: 100%">
            <w-image w-for="p in photos traceby p.id"
                     :url="p.full" :thumb="p.thumb" :full="p.full" w-zoom-lense></w-image>
        </Carousel>
    </div>
</div>
```

Главной нужна цепочка `height: 100%` от контейнера до слайда: контейнер → карусель → `.wg-track` → `.wg-slide` → `.wg-image`. В демо-файле она прописана в стилях.

Превью снизу — то же самое, только без `direction` и с `per-view` по ширине:

```html
<Carousel name="p2"> ... </Carousel>
<Carousel :thumbs-of="p2" :per-view="{ base: 4, md: 6 }" :gap="8"></Carousel>
```

## 13. JS API

Три слоя, от простого к прямому.

### jQuery

```js
$('#gallery1').wCarousel('next')
$('#gallery1').wCarousel('prev')
$('#gallery1').wCarousel('goto', 3)
$('#gallery1').wCarousel('index')     // текущий слайд
$('#gallery1').wCarousel('refresh')   // пересчитать вручную
```

Имя `wCarousel`, а не `carousel`: второе занято Bootstrap.

### Объект карусели

```js
const c = WGallery.carousel('#gallery1')   // селектор или элемент
c.next(); c.prev(); c.goTo(2); c.goTo(0, true)   // true — без анимации
c.index; c.count; c.maxIndex
```

### Глобальное

```js
WGallery.lightbox.open([
    { src: 'a.jpg', alt: 'Лес', caption: 'Подпись' },
    'b.jpg',                      // строка — тоже можно
], 0)
WGallery.lightbox.close()

WGallery.configure({ lens: { zoom: 3 } })
WGallery.refresh()                // пересчитать все карусели
WGallery.scan(element)            // найти и поднять карусели внутри узла
```

`scan` нужен только если вы вставляете `.wg-carousel` вручную в обход Wex. Через `MutationObserver` плагин и так подхватывает появившиеся карусели сам.

## 14. Настройки

Задать можно двумя способами, результат один:

```html
<script>
    window.WGalleryConfig = { lens: { size: 200 } }   // до подключения плагина
</script>
<script src="wex-carousel.js"></script>
```

```js
WGallery.configure({ lens: { size: 200 } })           // после, до mount()
```

Глубокое слияние: меняете одно поле, остальные остаются.

```js
{
    styles: true,                  // инжектировать встроенный CSS
    respectReducedMotion: true,    // prefers-reduced-motion отключает анимацию и автослайд

    breakpoints: { sm: 640, md: 768, lg: 1024, xl: 1280, '2xl': 1536 },

    image:    { lightbox: true, lazy: true },

    carousel: {                    // значения, когда проп не указан
        autoslide: false, interval: 4000, loop: false, hoverPause: true,
        dots: false, arrows: false, direction: 'horizontal',
        perView: 1, gap: 0, step: 1, start: 0, mouseDrag: true,
    },

    lightbox: { loop: true, closeOnBackdrop: true, preload: true, lockScroll: true },

    lens:     { size: 160, zoom: 2.5, shape: 'square' },

    classes:  { dot: '', dotActive: '', arrow: '', thumb: '', thumbActive: '' },

    i18n: {
        prev: 'Previous', next: 'Next', close: 'Close', slide: 'Slide {n}',
        counter: '{i} / {n}', error: 'Image failed to load',
        viewer: 'Image viewer', carousel: 'Carousel',
    },
}
```

Русификация:

```js
WGalleryConfig = { i18n: { prev: 'Назад', next: 'Вперёд', close: 'Закрыть',
                           slide: 'Слайд {n}', error: 'Не удалось загрузить' } }
```

`classes` — это мост к Quas. Хотите точки в своём стиле, не трогая CSS плагина:

```js
classes: { dot: 'w-3 h-3 rounded-full bg-white/60', dotActive: 'bg-white scale-125' }
```

Выключили `styles: false` — стили пишете сами целиком. Список классов в [стилизации](#15-стилизация).

## 15. Стилизация

### CSS-переменные

Ставьте на любого предка или на `:root`.

| Переменная | Что красит |
|---|---|
| `--wg-arrow-bg`, `--wg-arrow-color` | Стрелки карусели |
| `--wg-dot`, `--wg-dot-active` | Точки |
| `--wg-fit` | `object-fit` в `<w-image>` (по умолчанию `cover`) |
| `--wg-thumb-active` | Рамка активной миниатюры |
| `--wg-thumb-ratio` | Пропорции миниатюры (по умолчанию `1`) |
| `--wg-focus` | Цвет фокуса |
| `--wg-overlay` | Фон лайтбокса |
| `--wg-lb-z` | `z-index` лайтбокса |

```css
:root { --wg-overlay: rgba(10, 10, 20, .95); --wg-fit: contain; }
```

### Классы

| Класс | Элемент |
|---|---|
| `.wg-carousel` | Корень |
| `.wg-track` | Прокручиваемая лента |
| `.wg-slide` | Слайд. `.wg-active` — текущий |
| `.wg-arrow`, `.wg-prev`, `.wg-next` | Встроенные стрелки |
| `.wg-dots`, `.wg-dot` | Точки. `.wg-active` — текущая |
| `.wg-thumb` | Миниатюра. `.wg-active` — текущая |
| `.wg-image` | Обёртка `<w-image>` |
| `.wg-lb`, `.wg-lb-img`, `.wg-lb-bg` | Лайтбокс, картинка, фон |
| `.wg-lens` | Лупа |

Внутренние переменные `--wg-pv` и `--wg-gap` плагин ставит сам. Руками не трогайте, для этого есть `per-view` и `gap`.

## 16. Клавиатура и доступность

**Карусель** (в фокусе): `←`/`→` (в вертикали `↑`/`↓`), `Home`, `End`.

**Лайтбокс**: `Esc`, `←`/`→`, `Home`/`End`, `Tab` не выходит за пределы окна. Фокус возвращается на триггер.

**Автоматически:**
- у карусели `role="region"` и `aria-roledescription="carousel"`, у слайдов `"slide"` с номером;
- `aria-live="off"` при автослайде, `polite` без него;
- у кнопок `aria-label`, тексты в `i18n`;
- `<w-image>` с лайтбоксом получает `tabindex="0"` и `role="button"`, Enter и Space открывают;
- `prefers-reduced-motion` отключает анимации, плавный скролл и автослайд.

Автослайд ставится на паузу при наведении мыши, касании, фокусе с клавиатуры, скрытой вкладке и когда карусель вышла за экран.

## 17. Как это устроено

Три принципа.

**Компонент генерирует, рантайм живёт.** `<w-image>` и `<Carousel>` на этапе компиляции Wex выдают статичную разметку с классами `wg-*` и `data-wg-*`. Поведение — отдельный рантайм: делегирование событий на `document` и `MutationObserver`. Wex перерисовывает шаблон по diff-у, а рантайм после каждого патча пересчитывает всё сам: точки, стрелки, активные классы, ленты превью. Отсюда устойчивость к перерисовкам.

**Слайдер — это скролл.** Не `translateX`. Браузер держит инерцию, снап и вертикаль. Активный слайд определяется по позиции скролла, а не по счётчику, поэтому свайп пальцем и клик по точке дают одно состояние.

**CSS решает ширину.** Плагин не считает пиксели слайдов. Он читает `offsetLeft`/`offsetTop` реальных слайдов. Поэтому `md:w-1/4` из Quas и `per-view` — равноправные способы.

Побочные эффекты, о которых стоит знать:
- карусели не вешают на себя события через Wex, всё вне его системы реактивности;
- `<w-image>` и `<Carousel>` — функции компиляции, а не `View`-компоненты. Правило Wex «принимаются только пропсы из состояния ребёнка» к ним не относится: принимается любой атрибут;
- локальные `.component()` не нужны, компоненты глобальные;
- без Wex галерея тоже работает, если написать разметку руками (`.wg-carousel > .wg-track > .wg-slide`) и `data-wg-*` атрибуты.

## 18. Грабли

| Симптом | Причина | Лекарство |
|---|---|---|
| Картинок нет, в DOM `<img :url=...>` | Написали `<Image>` | `<w-image>` |
| Всё после компонента съехало | Самозакрывающийся тег `<w-image />` | `<w-image></w-image>` |
| Стрелка показывает «‹» как текст, дальше разметка ломается | Голый `<` в `w-navigate-left` | `&lsaquo;` или `&lt;` |
| Вертикальная карусель схлопнулась | У родителя нет высоты | Дать высоту или flex-stretch |
| Превью из цифр, а не картинок | У слайдов главной нет `src` (картинки не дошли) | Проверить, что `<w-image>` отрендерился |
| Превью не находят главную | Опечатка в `name` / `thumbs-of` | Строки должны совпадать точно |
| Автослайд встал на конце | Нет `loop` | `:loop="true"` |
| Автослайд не идёт на странице | Мышь над каруселью, фокус или вкладка скрыта | Это `hover-pause`, а не баг. Выключить: `:hover-pause="false"` |
| Лайтбокс не открывается при свайпе | Так и задумано | Клик отличается от жеста больше 6px |
| Лупы нет на телефоне | Нет hover | Так и задумано |
| `$('#c').carousel('next')` не работает | Имя занято Bootstrap | `wCarousel` |
| `w-for` внутри карусели мигает | Нет `traceby` | Всегда `traceby` для объектов |
