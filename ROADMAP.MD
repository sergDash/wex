# ROADMAP

Wex: реактивный шаблонизатор для тех, кому React и Vue избыточны

Пишете обычный HTML с {{ }} и директивами. Меняете обычные объекты, а остальное делает движок. Никакого сборщика, JSX и специального синтаксиса состояния.

Пишете, как думаете
- Реактивность без обёрток. state.count++, list.push(x), delete state.key сразу обновляют экран. Вложенные объекты тоже отслеживаются, ref() и setState() не нужны.
- Передача по ссылке. Пропсы и общий стор указывают на те же данные. Родитель и ребёнок видят одно и то же, ничего не копируется.
- Понятные выражения. ScopeX — собственный JS-подобный парсер выражений на основе Angular Expressions, с фильтрами {{ price | currency }}.

Быстрый и предсказуемый рендер
- Батчинг. Сто изменений подряд дают один рендер в микротаске.
- hold() / release(). На время drag-and-drop или тяжёлой анимации рендер можно приостановить, а затем выполнить одним синхронным проходом.
- Умный diff. Списки с traceby сопоставляются по стабильным ключам. Узлы и целые компоненты переезжают между контейнерами вместе с состоянием, а не пересоздаются. Для канбан-досок это решающий плюс.
- Постепенное монтирование. Сотни компонентов монтируются порциями по кадрам, поэтому интерфейс не замирает на старте.

Компоненты, которые не мешают друг другу
- У каждого компонента своё состояние, методы, жизненный цикл и изолированная область видимости.
- Компонент может лежать в отдельном .html-файле или подгружаться лениво вместе со своими данными.
- Можно использовать слоты, события @evt и общий стор.

Расширяемость
- Движок расширяется через плагины, директивы и компоненты. Роутер, w-lazy, w-prefetch и модалки написаны этим же публичным API, без закрытых хуков.
- У директив есть mounted, updated и unmounted, а также хранилище данных на каждом элементе. Подписки и таймеры чистятся в одном месте.

Данные и загрузка
- $wire даёт декларативный HTTP: get().to(state.posts), стратегии слияния, префетч по hover и общий индикатор запросов.
- Ленивые списки w-lazy бесконечно подгружают данные вниз и вверх, при этом сохраняя позицию прокрутки.

Диагностика из коробки
- На localhost движок сам показывает цепочку компонентов Root › Menu › Item, выражение, доступные переменные и кликабельный элемент.
- WEX_PROFILE выдаёт время compile, diff и affect по каждому рендеру.

Куда движемся
- Переход на fine-grained обновления, то есть точечные изменения DOM без пересчёта поддерева.
- Постепенный отказ от jQuery. Он нужен только как слой совместимости.
