# Создание Пулл-реквестов

Для того чтобы исправить баг или внедрить фичу, Вам необходимо создать 
пулл реквест в репозиторий. Он обязательно должен содержать следующее:
- Папка `PR`
- Внутри папки старый скомпилированный wex.js с нужным плагином для сравнения
- Рядом 2 демонстрационных HTML
- Первый HTML показывает баг или отсутствие фичи и подключает старый wex 
- Второй HTML показывает внедрение фичи или исправление с новым wex.js 

Править разрешается любой файл проекта.
